# 0.3交付与未完成清单

本轮响应的问题：学习目的和步骤不清楚；教材归属未落实；原典推荐被误当教材；没有背诵入口。此前0.2是技术试用，不是完整按教材学习的产品。

## 用户可以直接看什么

- 产品说明与五条学生故事线：PRODUCT-WHITEPAPER.md。
- 实际操作手册：STUDENT-MANUAL.md。
- 教材与词义规则：LEXICAL-PROVENANCE.md。
- 登录后 https://wyw.ericmo.top/#guide 阅读简明手册并下载上述三份文件。

## 本轮已实现并验证的范围

默认开始页按“找课文→读原文→查词→比课内例句→练背诵/辨析”说明用途。

“学课文”分开课内目录的已比对部分和待核试读资料；移除把学生送进正式空库的旧按钮。用户已有阅读和答题记录保留。

目前登记所查电子本中六上1个课文位置、七上7个文言选文位置，共8条目录关系。上传文档标题标称2024秋版；版权页未取得明确版次年月，也未确认孩子学校当前使用印次，因此不写“当前全部教材已核实”。

七上《咏雪》《陈太丘与友期行》《论语》十二章从旧的六年级推荐移回所查目录的七年级位置。其他未经核验的推荐不计入课内。

目录关联显示教材、真实年级、上下册、单元/课号、课名、印刷页、版本说明和来源。词卡先展示已比对目录中的课内例句，待核例句需要主动展开且最多2条；未核教材归属不擅自改叫课外。

本句注释登记5处比对结论，包括“顾”在《陈太丘与友期行》和《狼》中的不同用法。一般候选解释与本句教材注释分别展示；本库用法数不冒充古汉语词典全部义项数量。词语索引提供实词/虚词/指代等候选教学分类，明确教材未核定部分不冒充标准标签。

自主背诵可选择句段、全文朗读、关键词提示、遮挡回忆、揭示单句、记录提示使用、保存自评和从历史恢复原范围。关键词提示也计提示，切换到隐藏不会清零；重新独立练习须显式开始新一轮。保存原文版本与摘要；原文改变后不静默套用旧范围。记录独立于词义答题，不声称ASR识别或自动通过。

## 测试和发布

领域/接口测试41项通过，包含迁移可重入、来源状态不提升为审批、纠正后的六/七年级归属、背诵自评的提示约束、跨篇句段拒绝、独立记录、内容变化检测和家庭隔离。浏览器结果见browser-0.3.json；在隔离的测试门禁下运行，不修改线上认证。公网未登录边界见public-0.3.json。

生产仍使用公共EmailAuthMiddleware、原有Uvicorn服务与CF域名；仅重载本项目。公共认证SDK未修改，未自动发送邮件。数据库新增002_recitation.sql，旧学习记录保留；升级前备份在.local/backups/0.3/before.sqlite。

## 仍然没有完成什么

- 全部小学高年级、初中四年现行教材的逐册准确目录与版权版次。
- 全部实词/虚词的义项归纳、逐实例教材释义匹配和人审。
- 展示原文与教材文本的全部逐字差异校准。
- 语音陪背、默写OCR、多名孩子独立档案、科学验证的教学效果。

因此这轮完成的是文档、学习动线、部分教材证据与自主背诵。不能把它称作完整教材知识产品。下一项内容工作应逐册建立“版权页→目录→课文→本句注释”的台账，而不是继续按文章数量扩充未核资料。教材体系已经由用户确定，不需要再询问是否采用上海五四人教版；缺的是真实版次和正文注释证据。
