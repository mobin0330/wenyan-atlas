# 学习工作台 · Operate / Read

## Direction contract
THESIS：从一个词的具体用法出发，让跨篇对照在首屏发生。拒绝全库星空、聊天首页和统计卡片墙。
OWN-WORLD：清透白、鼠尾草绿的导航区、墨绿选择状态；紫色表示义项、蓝色表示原文实例，所有类别有文字。正文系统黑体，原文宋体。少量圆角服务触控，不用插画装饰学习内容。
STORY：先看“之”，选一种用法，读两处原句，回到原文，再试一道辨析。没有教材数据时诚实呈现空目录，并让公开原典样例可独立体验。
FIRST VIEWPORT：桌面左侧导航与范围，中部标题、搜索、局部关系图，右侧原句证据。移动端顶部导航、范围折叠，中心词和用法列表在前，关系图按需打开；不依赖拖图才能学习。
FORM：候选依次为 1 校园图书索引的克制蓝，2 科学课分类展板的分组色，3 植物标本分类的白绿与对照标签，4 校刊的蓝墨排版，5 地铁导视的色与路径，6 绘本跨页的图文层级，7 字帖的字距与黑白对比。采用第三候选，只借类型、色彩、密度和“路径随选择高亮”动作，控件仍为标准 Web 控件。seed:b0dee5b8b39d977b。
挑战方向评估：数据密集条码/格网字体降低儿童阅读清晰度；透明手册层叠和卡带外观引入无关隐喻；通用暖色卡片不优于本方向的证据对照。吸收的是一致分组和选择反馈，不复制外观。用户已授权合理判断且仅真正阻塞问题需询问，本轮直接采用此工作方向，不虚构用户审美批准。
