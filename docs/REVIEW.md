# 项目评审与产品规划

评审日期：2026-11-04。用户的 v1.0 文档是目的与需求参考，技术栈并非约束。本文件记录本轮重新判断，不以功能数量作为完成度。

## 产品判断

真正要解决的是“学生在这一句会解释，换一句就不会判断”。单篇阅读、词典检索和背诵都可以是入口，但产品的最小价值单位是 **一个具体用法及它的跨篇证据**。知识地图负责呈现联系，练习负责验证这些联系是否被理解。

建议首个可验证承诺：学生可以从一个熟悉例句出发，对照另一篇的用法，说明两者相同或不同的依据。暂不承诺提分、提高记忆或全教材覆盖。

## 痛点到解法

| 痛点 | 产品解法 | 首版的验证方式 |
|---|---|---|
| 每篇重新记注释，知识割裂 | 原文中的出现实例连接同一用法，按语境对照 | 学生能从原文跳到另一篇并返回原句 |
| 一词多义生搬硬套 | 字词、义项、出现实例分层；不把所有释义堆在字上 | “听之”与“射之”同属指代，但指代对象分别解释 |
| 图谱看起来复杂 | 默认局部图；手机默认文字关系；用法是可操作的焦点 | 不拖图也可完成全部学习任务 |
| 会浏览不等于会用 | 先独立判断，必要时提示，提交后解释 | 看卡片不提高掌握状态；提示答对单独记录 |
| 只在熟悉句子答对 | 跨篇比较与新语境迁移分开评价 | 当前含跨篇辨析，但尚不宣称严格未见语境迁移 |
| 错误被过度诊断 | 把错因表述为候选，回到证据再试 | 不从一次选择题宣布固定能力缺陷 |
| 版本混用与解释失真 | 原文核对、释义审核、教材归属三条独立证据链 | 样例绝不计入教材覆盖；正式视图逐层检查审核状态 |
| 复习记录造成压力 | 显示“待巩固/初步理解/到期复习”，不用排行或分数宇宙 | 学生知道下一步看哪一种用法 |

## 确定需求、建议与待验证项

确定：五个多选范围、默认小学、真实年级与版次保留；原文与用法双向跳转；跨篇证据；未审不发布；学习证据分能力类型；移动端可用；全局公共认证直接复用。

建议性方案：Next.js、React、Tailwind、Cytoscape、Drizzle、独立图数据库都可替换。本轮采用更小的 Python/SQLite/原生浏览器栈；地图关系由数据投影，SVG 只画局部几何关系。

需要核验：当前教材版次、具体年级篇目、选段与字形差异、注释标准、资源使用权限、读音与句式分类、有争议用法。AI 可以产出候选，不是审核者。

需要产品研究：小学与初中是否需要不同默认解释密度；学生是否理解“主谓之间”等术语；先看图还是先看例句；小范围结构图是否优于并排例句。当前选项是可逆的工作假设。

## 重大遗漏与本轮处理

1. **首次使用和教材版本选择**：五个范围不能代替版次选择。首版尚无教材绑定；后续应单独选择“学校使用的教材版本/学年”，或由家长设置一次。不能根据年龄猜教材。
2. **学习者身份**：一个家庭可能有多个孩子。当前私有门禁只表达进入同一空间的资格，不表达学习者身份。首版明示家庭共享记录；正式长期使用前增加独立学习者档案，且与公共认证门禁分离。
3. **错误分类不是唯一真值**：同一“之”有不同语法解释体系；记录审核依据，争议项保留，不强行统一。若教材解释与原典研究不同，展示两种视角并说明适用范围。
4. **原文版本与标注偏移**：现代标点、简繁转换、选段截断会使位置失效。保存底本与显示文本；出现实例验证字符区间；已发布文本不能原地替换，应新版本重审。
5. **问题的学习泄漏**：刚看到答案立即答对不是迁移证据。当前模型明确为“初步理解”；后续记录曝光、提示、题目版本和延迟间隔，迁移测验必须使用未呈现例句。
6. **隐私、撤销与导出**：本轮不收集语音照片，不调用外部 AI。样例记录只在浏览器，支持清除；私有数据库备份可恢复。跨设备同步、学习者删除/导出待正式上线前补齐。
7. **审核生产能力**：需要明确谁审核、每条多久、争议谁决定。当前只有来源工作单和 CLI 审核审计链，没有伪造教师审核。大规模内容管理界面尚未完成。
8. **离线与更新**：manifest 不等于完整 PWA；不缓存带身份的接口或未审核内容。离线包应带签名/版本与撤回机制，后续单独实现。
9. **范围之外的联系**：切换范围保留记录；后续允许用户主动查看范围外关联并标注年级，默认不混入当前练习。当前样例是独立集合，不冒充范围外教材。
10. **可访问性和失败状态**：列表替代图、键盘、原文焦点、无数据/错误/加载/提示/错答状态已实现；实际 iOS Safari、读屏和儿童可用性仍需设备验证。

## 信息架构与最短动线

四个学生入口：知识地图、按课本学、辨析练习、我的积累。来源工作单是辅助入口。

知识地图：词语 → 选择用法 → 看原句证据 → 回原文/做辨析。
课文：目录 → 原文（默认仅重点字词）→ 点词 → 用法图；纯原文、解释、重点词读音互斥切换。
练习：独立选择 → 可选提示 → 提交 → 证据解释 → 回图/换题。
积累：按用法展示证据状态，不展示虚构总体掌握率。

## MVP 边界重新划分

本轮 0.1 是 **原典样例驱动的可运行产品试验版**。阶段 0 完成技术与数据可行性调查、来源/缺口清单、模式和样例；逐册教材与人审是尚未关闭的数据关口。阶段 1 完成主要交互与发布约束的实现验证，但未达到完整正式内容 MVP 的验收。

优先前置一小组辨析题，使图谱价值可测试。AI 聊天、故事生图、语音、OCR 和视频继续后置；不做只会展示无法使用的 AI 按钮。

## 学习效果验证方案（计划，尚未实施）

先邀请 5–8 名目标阶段学生，在家长/监护人同意下做可用性试验，观察从词到另一篇的任务是否无需提示完成，记录卡住的术语与跳转，而非只问是否好看。随后以相当难度的词义材料比较“例句对照”和“关系图+对照”，分别记录首次辨析、未见语境、7 天延迟保持及学习耗时。样本小只用于迭代，不宣称统计显著或科创原创性；原始数据去标识化，不收集不必要的音视频。

退出指标应在试验前约定：是否自主完成、是否说出判断依据、错因推断是否被后续题支持。不能把页面停留或展开节点数当作学习成功。
