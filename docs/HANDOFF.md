# 接手指南

先阅读 [PRD](PRD.md) 和 [实际进度评审](PRODUCT-REALITY-REVIEW.md)。当前为 0.3 可交互学习原型。目标教材选版已确认。内容研究、学生可见目录和正式审核发布是三个独立状态。

| 入口 | 负责内容 |
|---|---|
| `server.py` | 本机三篇样例预览，标准库 HTTP |
| `asgi_app.py` | 私有试用 API、共享安全模块适配 |
| `atlas.py`、`migrations/` | 导入、SQLite、图谱、练习及内容审核 |
| `curriculum.py`、`data/curriculum-evidence.json` | 当前学生端部分教材关联 |
| `recitation.py`、`static/` | 自主背诵记录、浏览器学习流程 |
| `data/trial.json`、`data/contextual-gu.json` | 可重新导入的候选数据 |
| `data/textbook-*.json`、`scripts/` | 教材调研、候选整理与报告生成 |

## 优先工作

1. 逐册固定最新正式版目录及来源，从六上《曹冲称象》开始核验并接入完整课文。区分研究条目、原文已接入和审核已发布。
2. 改造只覆盖六、七年级的部分目录映射，让全部册次由版本与归属数据驱动。保留已有作品标识和学习记录，按册验证目录及可打开内容。
3. 按课文校准选段和分句，把注释对应到本句位置。修正合篇提取串行，补齐重点词、读音、义项和教学要求。
4. 验证同义和异义跨篇例句，再扩充可信练习及背诵范围。通过实际学生动线验收后再评估学习效果。

## 资料与运行依赖

Git 仓库提供候选数据、来源元数据和可重新生成的报告。原始教材扫描、第三方全文缓存、私有数据库、学习记录、服务凭据和证书由本机单独保管。重跑教材研究脚本需要重新按 [教材研究报告](TEXTBOOK-RESEARCH.md) 获取合法来源缓存，或者通过授权渠道交接缓存。一般开发可以直接使用已提交的数据。

本机预览只需 Python。完整私有试用和认证测试需要工作区共享 `security-service`，接手人需通过已有维护者取得该依赖及自己的部署凭据。具体步骤见[运行与部署](OPERATIONS.md)。
