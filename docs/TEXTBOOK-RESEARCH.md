## 实词、虚词与其他知识如何梳理

实词、虚词是教学归类层，具体词性与本句语法功能另列；代词、副词等归类可能随教学体系而不同，必须注明本产品采用的依据，不能宣称教材对每个字都给出统一分类。通假、古今异义、词类活用属于文言现象，特殊句式属于句子层，人物、事件、文化常识分别存储。

每个正式知识实例必须形成：指定教材版本 → 年级/册/单元/课文 → 段落/原句 → 词语位置 → 本处读音与义项 → 词性/语法功能 → 教材注释位置与依据 → 审核状态。一个字的多个用法不能全部套到每一句。

当前词头提取结果属于候选：包括专名、短语、同组子篇重复项及OCR误差，不是“全部实词虚词已解释”。合篇注释还没有全部分配到子篇和本句，尚未批量导入学生知识地图。

## 背诵任务的关键辨别

六上：所见版本的背诵指令指向《两小儿辩日》，不让《曹冲称象》继承。四下：背诵指令指向《囊萤夜读》，不让《铁杵成针》继承。六下：所见修订本明确熟读《学弈》《关尹子教射》，不凭旧印象加必背。七下：《陋室铭》《爱莲说》有背诵并默写要求。八上：《富贵不能淫》在所见版本要求指定片段；九下《送东阳马生序》在所见版本要求前两段。背诵和默写记录继续独立。

## 后续内容工作顺序与验收

1. 18册逐一核实最新正式修订版的版权版次，对照官方目录解决修订差异；保留旧版记录，不互相覆盖。
2. 确认每课的古代正文选段、字形、标点、分段，古诗词和古典白话小说另列。
3. 按本句位置逐条整理教材注释对应的义项、读音、词性、文言现象和句式，完成跨篇同义/异义归并。
4. 核清每一条背诵、默写任务对象、范围和出处，不能由AI猜测或按合篇自动继承。
5. 经内容审核后分批进入学生端，并给出当前指定版的实际分母和覆盖率。

本轮没有宣布上述1–5全部完成，也没有把历史目录、第三方OCR或AI候选标成人工审定知识。
