# 文言星图使用手册

适用入口：https://wyw.ericmo.top 。本手册区分已实现操作与仍待补齐内容，不把产品愿景写成现成功能。

## 第一次打开，先做什么

用统一邮件验证码登录。进入“学课文”，保留或调整学习范围（小学、六、七、八、九年级，可多选，至少一项）。教材体系固定为上海五四学制人教版；不用另选其他学制。

看课本或课文上的状态：

| 状态 | 可以据此认定什么 | 不能认定什么 |
|---|---|---|
| 教材目录已比对 | 这篇在所列电子本和册次的目录中 | 全部释义已核验、与你家当前印次完全相同 |
| 教材注释已比对 | 所列本句的释义已与指定注释位置比对 | 此词全部义项都已完整收录 |
| 教材归属待核 | 可以看待核阅读材料 | 不能当作确定课内例句 |
| 课外拓展 | 是主动展开的补充材料 | 不能计入教材覆盖或默认练习范围 |

若当前范围没有已比对的课本，不再把空白当成学习页；先看教材核对清单，或者主动进入待核试读。当前有可操作的七上目录核对示例，其他册次仍需补齐。

## 日常学习一次：读 → 查 → 比 → 练

1. 在“学课文”打开一本教材，再打开课文。先核对课名和册次。
2. 先读原文。顶部可切换纯原文、重点字词、解释、重点词读音。整句解释待补时会明确显示，不能把空解释当成已经讲解。
3. 点击高亮词。先看本句是什么意思，再看这个词已收录的其他义项。
4. 展开用法。课内出处优先显示教材全称、册次、课名和页码；点击“回到原文”可回到对应句子。
5. 选择“用一道题试试理解”。先独立答，必要时再看提示，提交后看依据。候选题有标记，尚不能用它当正式考试评分。
6. 看“我的积累”。看过只记已读；答题、提示使用、背诵自评各自记录。

不必先学会拖动图。手机默认文字用法；电脑可以用关系图，也可以切换文字视图。

## 怎样练背诵

从课文页点击“练背诵”。先核对这份显示文本与你手中教材和老师要求是否一致；未校对文本可以试用练习，但不能当作教材标准背诵检测。

1. 勾选今天要练的句段，不勾选的不会混进本次练习。
2. “看全文朗读”：先把句段读顺。
3. “关键词提示”：保留少量提示，其余内容隐藏。
4. “遮住原文回忆”：自己出声背，卡住时仅“看这一句”。
5. 核对后选择自评结果并保存。页面说明用了几次揭示；不能在用了提示后保存为“无提示独立完成”。
6. 下次打开课文，查看背诵记录，继续练上次的句段。

**没有录音自动评分。** 系统不会判断你是否真的读出来，也不会凭自评宣布已经通过背诵。语音陪背和默写OCR尚未实现。

## 怎样查一个字有几种意思

在搜索框输入字词。词页显示“本库已收录N种用法”，逐项列义项、实虚分类候选、具体词性/功能和例句。这个N不是古汉语词典的全部释义数量。

每条确定的课内例句都应有：教材—册次—版本说明—篇目—原句—页码—本处解释依据。尚未取得依据的，显示待核，不能用古籍地址替代教材地址。

当前教材范围外的课内例句仍应标明它属于哪册；课外例句另行展开，最多1–2条，不抢在课内前面。

## 《司马光》应怎样理解

它可以作为过去学过的课文参与关联；不能因为名称熟悉就默认它属于当前所选教材版次。必须先补齐所据课本、年级、册次、版本和课文位置。人教社曾说明《司马光》收入三上，但这一旧版统编说明不能直接证明当前五四版的全部对应。当前未补齐的条目仍为待核材料。

## 我看到空目录怎么办

先看页面是否处于待核资料或课内目录，而不是反复切年级。0.2曾有一个“查看教材目录状态”的按钮，进入没有发布数据的空目录；0.3不再把这个按钮当作正常学习步骤。

没有目录意味着教材数据尚未完成，不是你不会操作。可以通过“产品手册”查看当前支持范围；发现与手中书不一致时，以学校教材为准，不靠多刷候选题解决。

## 记录和隐私

线上版本为一个家庭共享空间，记录保存在Mac mini；尚不区分兄弟姐妹。纯本地样例则只在浏览器保存。背诵是自主练习，不收集声音；当前无手写照片上传。不要把共享记录当作某一个孩子的完整画像。

## 还不能期待的功能

全部现行教材逐册覆盖、全部字词的教材注释核验、真正的语音纠错、纸笔默写识别、AI故事、科学验证的掌握度，以及多个孩子独立账户。状态随交付验收表更新，不能因为入口存在就认定已完成。

背诵补充：进入关键词模式也计一次提示，切到遮住模式不会清零。要独立重试，点击“开始新一轮”；历史记录的“恢复这次范围”会还原句段选择并开始新一轮，原自评保留。原文变化时先核对，不自动套用旧范围。
