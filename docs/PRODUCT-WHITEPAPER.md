# 文言星图：产品说明与学生故事线

文档版本：0.3。教材范围已确定为 **上海五四学制、人民教育出版社统编语文**。学生选择的年级只是过滤条件，不能代替具体教材、册次和版次。本文的“目标流程”不是已经实现的声明；当前实现另有验收表。

## 这个产品帮助学生完成什么

学生在学校学了一篇文言文，回家要完成三件事：读懂本篇、按老师要求记住或背会、把这里学过的词用到另一篇。产品围绕学校课文组织这些任务。知识地图的作用是把例句连起来，帮助比较；学生不需要先学会操作一张图。

一次学习的最小成果，不是打开了多少个节点，而是学生能说清“这个词在这一句为什么这样解释”，并能在另一个句子里重新判断。背诵、默写与词义辨析是不同能力，分别记录。不能根据读过、点过或一次答对就宣布掌握。

## 故事一：跟着学校学今天的课文

**人物与情境**：七年级学生小林今天在学校学习《狼》，老师布置熟读，整理重点词。

**学生说**：“我想先找到我正在上的那一课，不想从整张知识图开始找。”

1. 进入“学课文”，选择上海五四人教版七年级上册；看到册次、所据电子本的版本说明和目录核对状态。
2. 找到第五单元第20课《狼》，先读原文。若当前显示的是原典整理文本，会明确告诉他尚未逐字校准教材，不能冒充教材原文。
3. 点击“顾野有麦场”的“顾”。卡片先解释本句，再列出处：七上、第20课、印刷页125、教材注释位置；原典出处是补充来源。
4. 切换到《陈太丘与友期行》中的“元方入门不顾”，比较“顾”的两种语境。每条都能回到课内原句，不能把“看、视”机械套成“回头看”。
5. 学生用自己的话说明两处意思。若有已核验题，可做一道辨析；若题目答案仍为候选，不当作正式评分依据。

**这次算完成什么**：本篇已读；完成了哪些本句用法的辨析另记。没有完成背诵就不显示“会背”。

**界面需要给出的支持**：课本是入口；词卡有课本位置；课内例句先显示；“返回原句”保留位置；没有数据时说明缺的是教材核对还是释义，不能只给空白页。

## 故事二：遇到熟字，却不能照旧解释

**人物与情境**：小林记得“去”常解释为离开，又在另一篇里遇到这个字。

**学生说**：“这句的‘去’是不是我以前学过的意思？我在哪篇学过？”

1. 从正在读的句子点击“去”，先看到“这一处采用哪种义项”，而不是把全部词义同时套进本句。
2. 词条展示“本库已收录几种用法，其中几种有教材注释依据”；这不是宣称这个字在全部古汉语中只有这些意思。
3. 展开一个义项，先列本范围内的课内例句，再列以前学过的课内例句。每条带教材、册次、课名、页码、定位和释义依据。
4. 未核验的材料不混进“课内”；最多1–2条课外拓展由学生主动展开，另外标“课外”。
5. 对两句作出判断，再返回正在学习的课文。

**学习价值**：让学生形成“看语境—找句中关系—回查旧例—比较判断”的方法，而不是背孤立释义列表。

## 故事三：老师要求背诵一段

**人物与情境**：七上学习《诫子书》，老师指定范围；学生总在中间一句卡住。

**学生说**：“让我先练容易忘的几句，别一上来要求整篇脱稿。”

1. 在课文页点击“练背诵”；页面显示所用文本版本，并提醒核对老师要求与手中教材。
2. 选择本次练习的一个或几个句段。这里叫“句段练习”，不把自动分句冒充教材自然段。
3. 先“看全文朗读”，再切换“关键词提示”，最后“遮住原文回忆”。
4. 卡住时点击某句“看这一句”，只揭示这一句，不一次展示全篇。
5. 完成后回到原文自行核对，记录“仍需练习／借助提示完成／自评独立完成”。记录提示次数（包括关键词模式与单句揭示）和文本版本。
6. 第二次打开能看到上次练到哪些句段；背诵记录与词义答题记录分开。

**当前边界**：本轮补的是无录音的自主背诵练习。它不自动听懂学生声音，也不自动判断漏字、顺序或发音。“自评独立完成”不能写成“系统认证背诵通过”。

## 故事四：复习以前学过的知识

**人物与情境**：学生在“我的积累”发现一种用法最近判断错过。

1. 看“本句用法”和上次练习时间，回到当时的课文位置。
2. 与另一篇已核验课文中的例句对照，再做新题。
3. 使用提示与独立完成分开记；一次错误只提示“可能混淆”，不能给学生贴固定能力标签。
4. 到期复习只是提示；先按透明规则工作，不宣传精确诊断或已经证实提分。

**当前边界**：现有家庭空间共用记录，尚未实现多个孩子的独立档案；这会影响长期学习效果测试，不能当成已经完成的个性化学习系统。

## 故事五：家长检查教材依据

**人物与情境**：家长发现一个解释与孩子手中教材似乎不同。

1. 打开词卡的教材溯源，确认学制、人教版、年级、上下册、所据版本、课文、页码和例句。
2. 区分“目录已经比对”“本句注释已经比对”“学校当前使用版次已确认”三种结论。
3. 有差异时保留两版各自的记录，不用AI覆盖教材；有争议的解释暂停作为确定答案。
4. 不要求家长在整篇古籍或搜索引擎里自己找一句话。

## 词语、现象和句式怎样分层

- **字词层**：实词/虚词是学习组织维度；名词、动词、形容词、代词、介词、连词、助词等是更细的词性或功能标签。不同语法体系的归类可能不同，必须记录依据。
- **本句用法层**：同一个字可在不同位置承担不同功能。实虚和词性标签要落到具体义项/出现实例，不能按字形给整字永久定类。
- **文言现象层**：古今异义、通假、词类活用等不是与实词/虚词并列的“第三种词”，而是附在本处用法上的现象。
- **句式层**：判断、省略、倒装、被动等属于句子关系；不能塞进词语释义冒充同一层。
- **教学措辞**：先用学生听得懂的话说明本句，再按年级展示术语。教材未做的语法细分只能标作补充分析，不能伪称教材标签。

## 当前真实完成度

0.2已上线的是原典阅读、局部关系与基础答题试用，教材版本/归属和释义核验没有闭环。扩充阅读材料数量并没有解决这一缺口。

本轮0.3目标是让学习动线可理解、教材证据可定位，并补齐可操作的自主背诵。只有逐册目录与本句释义都有证据的部分才能被称作课内教材知识；其余资料保留待核状态。完整教材覆盖、全部词义校准、语音陪背、默写OCR和多个孩子隔离仍须单独验收。

## 产品验收的顺序

第一关：学生能从学校课本进入本篇；第二关：本句解释有教材依据；第三关：另一篇同义/异义例句可以回到原句；第四关：可以练背并保留独立记录；第五关：用真实学生和未见语境验证是否有学习收益。前四关没有过，不能用功能数或题量代替产品完成度。

背诵补充：进入关键词模式也计一次提示，切到遮住模式不会清零。要独立重试，点击“开始新一轮”；历史记录的“恢复这次范围”会还原句段选择并开始新一轮，原自评保留。原文变化时先核对，不自动套用旧范围。
