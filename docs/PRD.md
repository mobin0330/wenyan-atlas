# 文言星图产品需求

依据最初的《AI 文言文知识地图｜产品需求与开发任务书 v1.0》及后续确认整理。当前实现进度单独见[产品实际进度评审](PRODUCT-REALITY-REVIEW.md)。

## 目标与范围

学生在不同课文中反复遇到同一字词，往往只能记住一篇下的注释。产品要帮助学生根据语境辨义、比较跨篇用法，再用新例句检验理解。核心路径是原句、具体用法、跨篇例句、辨析和复习。家长用于查证来源，教师可参与内容审校。

教材采用上海五四学制、人民教育出版社语文学生用书，小学一至五年级及初中六至九年级上下册。每册采用最新正式出版修订版，分别保存版权版次与使用学年。学生端提供小学、六年级、七年级、八年级、九年级五项多选，默认小学，至少保留一项。切换范围保留历史记录，并可查看明确标注的范围外关联。小学目录保留真实年级。古诗词、古典白话、课外诵读另行分类。目标设备包括手机、平板及桌面浏览器，面向 H5 和 PWA。

## 学生功能

| 模块 | 需求与验收 |
|---|---|
| 教材与课文 | 按年级、册次、单元、篇目浏览和搜索。提供原文、重点词、读音、解释及来源。读音、注释和译文按需切换。点词能看到本句解释，并可返回原句。 |
| 知识地图 | 区分字词、义项、读音、出现实例、语法功能、文言现象和句式。一个义项能连到多篇课文；每条例句可查教材、版次、册次、课文、页码与本句位置。支持局部展开、搜索、筛选、缩放及文字替代视图。课内依据优先，少量课外拓展独立标注。 |
| 课文与个人视图 | 课文视图归纳重点词、句式、人物和跨篇联系。个人视图区分接触、练习、混淆和待复习，用答题证据和时间计算状态。 |
| 故事化理解 | 先按篇目类型梳理人物事件、论证、景物或意象，再提供 3 至 6 张与原句绑定的图解或记忆卡。审核内容和人物一致性。视频后置。 |
| 背诵与默写 | 支持按课后要求或自选句段朗读、提示和遮挡。背诵、默写分别保存。后续支持语音与原文对齐、文字默写、拍照识别及手工修正，区分识别不确定与学生错误。 |
| 辨析与迁移 | 从审核例句中选择练习，先作答再提示。区分熟悉例句辨析和新语境迁移。错因作为假设，用后续题目验证。掌握度和复习规则可解释。 |

## 内容规范

采用“教材版次 → 课文选段 → 原句位置 → 词语出现实例 → 本处义项与功能”的证据链。实词与虚词是教学分类，语法功能落到具体用法。通假、活用、古今异义和特殊句式独立记录。每个重要关系保存来源、原文位置、证据、版本和审核状态。教材明确的解释优先，补充分析须标出依据，争议项保留不同解释。

先核准正式版目录，再对照原典与教材选段，整理课后要求、释义、读音和例句。课内背诵、熟读和默写范围独立记录。AI 和 OCR 生成候选，内容审核后进入正式学生库。现代教材注释、译文、配图按授权处理。使用古籍原文、原创解释及合法资料，保留来源与许可。

AI 可辅助结构提取、渐进提示、故事脚本、出题和错因分析。答案引用已核验依据，缺少依据时如实提示。目录检索、图谱查询、评分、学习记录和间隔复习优先用确定性程序。外部模型密钥仅在服务端。儿童语音及图片功能上线前需明确授权、保存与删除流程。

## 阶段验收

1. **阶段 0 数据可行性。** 交付逐册正式版本与篇目清单、来源和缺口、版权依据、结构与代表关系。目标覆盖分母以核准目录计算。
2. **阶段 1 知识地图 MVP。** 完成五项范围、教材目录、原文、点词、用法地图、搜索、审核和基础记录。按册验证每个目标篇目可打开，并按原句核查释义和来源。面向实际试用的内容范围包括小学高年级及完整初中四年。
3. **阶段 2 学习增强。** 完善分段背诵、结构图和故事卡，提供跨篇辨析、错题及基础复习推荐。
4. **阶段 3 学习闭环。** 增加语音陪背、默写识别、个性化复习与诊断，完善全册内容。视频作为探索项。

前端可使用局部图和文字关系卡。当前技术实现为 Python、SQLite、ASGI 和原生浏览器模块，运行目标为 Mac mini M4 16 GB。验收覆盖迁移、重复导入、范围筛选、关系一致性、主要学习动线、手机适配、性能与恢复。私有部署使用共享认证。真实学习效果另用新语境辨析、延迟保持和学习耗时评估。教师班级管理、付费、社交、自研模型和三维图谱后置。
