# 教材溯源与词义规则（0.3执行规范）

## 绑定范围

固定：上海五四学制，人民教育出版社统编语文。每本仍独立保存真实年级、上下册、版次/印次、使用学年；“上海五四人教版”确定不等于这些字段可以省略。不能把六三教材年级、旧版年级或试用推荐写成这个体系的确定归属。

## 一条释义的证据链

词语 → 义项 → 本句出现实例（句子与字符位置） → 篇目 → 教材册次 → 指定电子本/版权页证据。

本句解释另有自己的依据：教材注释或练习位置、页码、比对结论、比对时间、审核状态。目录比对不能代替注释比对；注释比对不能代替全文逐字一致；古籍正文链接不能代替教材来源。

同一个义项可以关联多篇课文；同一篇里同一个字的多次出现各有实例；与当前义项不相符的例句不得因字形相同自动连线。

## 展示与排序

1. 当前指定课本的课内例句；
2. 已选其他年级或已学过的课内例句；
3. 其他年级的课内例句（明确范围外）；
4. 用户主动展开的1–2条课外拓展。

归属未知不是课外，应单列“教材归属待核”。待核条目不得冒充课内，不计课内数量，不用于正式掌握判定。每条课内例句显示书名、年级上下册、版本说明、单元/课号、课名、原句、页码（未知明确标待核）和回原文动作。

## 解释和术语

“本库已收录N种用法 / 其中M种有教材注释证据”，不写“此字只有N种意思”。

实词/虚词、具体词性/语法功能、文言现象、特殊句式是不同层。定类基于本句，不按整个字永久定类。代词、副词等在不同教学语法框架中的归类要注明口径；教材没有定类时，前端只能写“教学分类候选”，不能写“教材认定”。

古今异义、通假、词类活用可与实词或虚词标签并存，但不替代义项。教材解释优先；原创解释必须能对应教材依据并保持学生可理解。未取得依据时，不用候选解释充当标准答案。

## 发布和验收

目录已比对、本句释义已比对、原文已逐字校准、人审已完成四种状态分别记录。只有满足所声称的证据条件才展示相应标签。所有变化保留旧记录，学生原有学习记录不删除。教材框架已由用户确认，不能再把“要不要采用这个教材”交回用户批准；真正缺的是具体原书证据，应明确列出缺哪册、哪页。
